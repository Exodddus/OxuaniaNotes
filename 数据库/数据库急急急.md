- SQL 语句

		- create
		- alter

	- 数据操作语言
		- select
			- 其中可以有表达式，例如 select amount * 10 as total_amount from loan 
			- SELECT A.brach_name, avg(balance) 
				FROM account A, branch B 
				WHERE A.branch_name = B.branch_name and branch_name = 'Brooklyn'
				GROUP BY A.branch_name
				HAVING avg(balance) > 1200
			- SELECT branch_name, avg_bal
				FROM (SELECT branch_name, avg(balance)
						FROM account
						GROUP BY branch_name)
						AS result (brach_name, avg_bal)
				WHERE avg_bal > 500
			- WITH max_balance(value) as
					SELECT max(balance)
					FROM account
				SELECT account_number
				FROM account, max_balance
				WHERE account.balance = max_balance.value
			- 聚合函数不能直接用在where语句中
			- 除了 COUNT (\*) 对表中所有行的数目进行计数之外，表列中包含NULL的行都会被忽略
